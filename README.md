# 🎓 Exam Platform

A full-stack exam platform for Egyptian secondary school students (Thanaweya Amma).

## ✨ Features

- 🔐 Authentication via Telegram + Username/Password
- 🎯 Quiz system with automatic grading
- 📊 Admin dashboard with statistics
- 🏆 Leaderboard
- 🌐 Arabic (RTL) + English (LTR)
- 🌓 Dark / Light mode
- 🤖 AI-powered motivational quotes & performance analysis
- 📱 Fully responsive

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL (Neon) + Prisma ORM
- **Auth:** NextAuth.js
- **i18n:** next-intl
- **Theme:** next-themes
- **AI:** Groq SDK
- **Bot:** node-telegram-bot-api
